## 🔬 Présentation

**H₂O Synthesis Console** est un tableau de bord interactif conçu pour l'analyse complète de la synthèse catalytique de l'eau par recombinaison d'hydrogène et d'oxygène.

> **2 H₂ + O₂ → 2 H₂O**

L'application couvre l'ensemble de la chaîne d'ingénierie : thermodynamique, cinétique, dimensionnement de réacteur, analyse économique, sécurité HAZOP et spécifications qualité. Interface sobre et dense, inspirée des outils métiers de l'industrie des procédés.

### Points clés

| | |
|:---|:---|
| 🎯 **Objectif** | Outil pédagogique et professionnel d'analyse procédés |
| ⚡ **Performance** | Application 100 % front-end, sans dépendance |
| 🎨 **Design** | Palette institutionnelle Bleu Blanc Rouge |
| 📊 **Modules** | 8 sections d'analyse indépendantes |
| 🔬 **Simulations** | Thermodynamique, réacteur, molécules, HAZOP |
| 📥 **Export** | JSON des paramètres, impression optimisée |

### Navigation principale

### Constructeur moléculaire

```
1. [+ Ajouter H₂]  → ajoute une molécule d'hydrogène
2. [+ Ajouter O₂]  → ajoute une molécule d'oxygène
3. [⚡ Faire réagir] → convertit 2 H₂ + 1 O₂ en 2 H₂O
```

Le panneau de résultats affiche le **réactif limitant**, la **quantité d'eau produite** et les **molécules en excès**.

### Réacteur catalytique

```
[▶ Démarrer]  → lance la simulation
[⏸ Pause]     → suspend la simulation
[Réinitialiser] → remet les compteurs à zéro
```

Le réacteur monte progressivement en température (25 → 250 °C), la conversion atteint 99,9 % en régime établi.

### Simulateur de fuite H₂

| Concentration | Niveau | Statut |
|:---:|:---:|:---:|
| < 0,4 % | Nominal | ✅ |
| 0,4 – 1 % | Alerte 10 % LIE | ⚠️ |
| 1 – 4 % | Alarme 25 % LIE | 🚨 |
| ≥ 4 % | Zone explosive | 💥 |

## 🛡️ Sécurité

> **Ce projet est un outil pédagogique de simulation.**
> Il ne doit en aucun cas servir de base à une installation réelle sans validation par un ingénieur procédés qualifié.

### Risques H₂ / O₂

- 🔥 **Hydrogène** — inflammable et explosif (4–75 % vol. dans l'air)
- 💨 **Oxygène** — comburant, accentue toute combustion
- 💥 **Mélange H₂/O₂** — détonant, énergie d'inflammation 0,017 mJ
- 🧊 **Stockage** — gaz comprimé réglementé
- 🧪 **Produit** — eau non potable sans analyse

### Normes applicables

| Norme | Domaine |
|:---|:---|
| **ATEX** | Zones 1/2 · IIC T1 |
| **ISO 22734** | Générateurs H₂ par électrolyse |
| **IEC 62282** | Technologies piles à combustible |
| **ASTM D1193** | Eau réactif de qualité |
